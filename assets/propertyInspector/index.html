App

Behaviour

What holding the key (about half a second) does. "Open another window" runs the launch command, with its Extra arguments, even when the app is open; single-instance apps (and most apps on macOS) just come forward.

Appearance & matching

Shown as the key's title.

An icon theme name, or an absolute path to an image (on macOS: a PNG, SVG or .icns file).

Matched exactly (ignoring case); on macOS this is the bundle id (e.g. com.apple.Safari). Only needed if the app reports a different one.

Only the app's windows whose title contains this text (ignoring case) belong to this key; with none open, the key launches. Pick text that stays in the title, like a project or site name. Linux only (KDE, GNOME, X11).

Launch

Replaces the app's own command. Run directly, not through a shell: quotes group words, nothing else is special.

Appended to the command, split the same way (on macOS, passed to the app after --args).
